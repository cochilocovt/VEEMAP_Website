## Commands

From the repository root:

```powershell

```

From `site/`:

```powershell

npm run lint
npm run build
```

Node.js 22.13 or newer is required.

## Content and UX constraints

- The brand is VEEMAP Technologies, an Indian industrial-automation and
  special-purpose-machine company.
- Ground claims in `docs/brand-context/`; approved headline proof includes
  236 projects, 55 clients, and five sectors.
- Support reduced motion and mobile access. Motion must explain engineering,
  not block reading or enquiry capture.
- Do not add a back end, CRM, upload field, or external submission service
  without explicit authorization. Contact details and public facts must come
  from the brand-context documents.
- The current hero machine is conceptual and non-proprietary; retain that
  framing until approved assets arrive.

## Known open decisions

- Deployment target and its external configuration are not fully settled.
- Lead submission destination, consent wording, and response expectations are
  undecided; the current experience intentionally prepares an email only.
- Official website design rules and production-ready 3D assets have not been
  supplied. The current design evidence is documented, not canonical branding.
