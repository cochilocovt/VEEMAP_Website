# VEEMAP concept-machine assembly

Use the supplied assembled machine as the visual anchor, not as an immutable
pixel template. The goal is a clear, conceptual exploded-to-assembled sequence.

- Keep the same overall machine identity, camera family, perspective, scale,
  black background, brushed-metal material language, lighting, and contrast.
- When the current prompt names a module, you may remove it, relocate it to a
  mechanically plausible exploded position, or install it.
- You may reconstruct surfaces hidden behind a moved or removed module so the
  result remains visually complete and mechanically believable.
- Prefer coherent geometry and a readable assembly state over exact pixel
  matching. Small local changes to rails, brackets, fasteners, highlights,
  shadows, and occlusion are acceptable when required by the edit.
- Change one named module group per step and carry all earlier changes forward.
- Treat each supplied state image as the authority for that step. Use the
  assembled image only as the reference for the final machine identity.
- Keep component paths straight, guided, and mechanically plausible. Installed
  parts must seat cleanly; exploded parts must remain separated and readable.
- Keep the machine conceptual and non-proprietary. Do not add dimensions,
  customer-specific tooling, readable HMI data, brands, labels, people, text,
  callouts, particles, or decorative effects.

Ask for confirmation before generating media or spending credits.
